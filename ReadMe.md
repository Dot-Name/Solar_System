# Solar System - 3D Web App

This project is a **3D Solar System simulation** built using the **MERN stack** (MongoDB, Express, React, Node.js) and **Three.js** for rendering 3D models. The application visualizes the planets, their orbits, and the sun, creating an interactive experience of our Solar System.

## Features
- **3D Solar System:** View the solar system with 3D models of planets and the Sun.
- **Interactive Controls:** Rotate and zoom into the scene using mouse movements.
- **Responsive Design:** The application is responsive and works across various screen sizes.
- **MERN Stack Backend (optional for future updates):** Backend setup with Node.js, Express, and MongoDB for storing additional data like planet information, animations, etc.

## Tech Stack
- **Frontend:**
  - **React** - For building the user interface.
  - **Tailwind CSS** - For styling the app with utility-first CSS.
  - **Three.js** - For creating 3D visualizations and rendering the Solar System.
- **Backend (optional for future enhancements):**
  - **Node.js** - For server-side logic.
  - **Express.js** - For building APIs.
  - **MongoDB** - For storing data like planet details, user settings, etc.
- **Deployment:**
  - Frontend hosted on GitHub Pages / Netlify.
  - Backend (if implemented) hosted on Heroku / DigitalOcean.

## Prerequisites
- Node.js (v14 or higher)
- npm (v6 or higher)
- A modern browser (Chrome, Firefox, etc.)
